# Verilog Libraries

This repository documents my Verilog implementations of common digital design building blocks and reusable hardware modules.

## Bus Arbiter
A bus arbiter determines which master is granted access to a shared bus when multiple masters request it simultaneously.

📖 See **[Bus_Arbiter/Arbiter.md](https://github.com/puneethreddy592/Verilog-Libraries/blob/7bb3af5e2b222b33ef13697c31df58d29160f9ca/Bus%20arbiter/arbiter.md)** for the implemented arbitration algorithms and their Verilog implementations.
