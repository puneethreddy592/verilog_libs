# Verilog Libraries

This repository documents my Verilog implementations of common digital design building blocks and reusable hardware modules.

## Bus Arbiter
A bus arbiter determines which master is granted access to a shared bus when multiple masters request it simultaneously.

📖 See **[Bus_Arbiter/Arbiter.md](Bus_Arbiter/Arbiter.md)** for the implemented arbitration algorithms and their Verilog implementations.
